## Description

Filter Condition Table

## Usage

```r
## S4 method for signature 'EvalHandler'
filter_cond(.data, ...)
```

## Arguments

- `.data`: A EvalHandler object.
- `...`: Logical predicates defined in terms of the variables in the condition table.

## Value

A EvalHandler object with pending filters.
