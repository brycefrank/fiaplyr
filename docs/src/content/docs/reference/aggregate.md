## Description

Aggregate Data to Plot Level

## Usage

```r
aggregate(handler, ...)
```

## Arguments

- `handler`: A handler object.
- `...`: A scoped target helper such as `tree(VOLCFGRS)` or `cond()`, plus any method-specific options such as `sparse = TRUE`.
